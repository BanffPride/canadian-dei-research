# Sponsorship and Partnership Tracking Platform

Working folder for the Banff Pride Society sponsorship and partnership platform. Gate-based delivery; nothing here changes live systems.

| File | Purpose | Status |
|---|---|---|
| `gate-1-decision-brief.md` | Gate 1 decision brief: current-state audit, recommended architecture, decisions requested | Awaiting ED approval |
| `source-index.md` | Inventory of every record reviewed, with Drive, Gmail, Granola and Todoist identifiers, confidence and verification flags | Maintained incrementally from Gate 4 |

Rules for this folder:

- No personal contact details, credentials or live financial exports. Organization names, roles, document IDs and thread IDs only.
- Signed agreements are referenced by Drive ID, never copied here.
- Gate documents are not edited after approval; changes go in a new gate document with version history.
